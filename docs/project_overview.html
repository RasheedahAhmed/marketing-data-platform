stg_facebook_stats

Typed daily facebook metrics. Exact duplicate raw rows collapse; conflicting rows at the business grain fail tests. Null impressions/clicks remain unknown.

ColumnMeaning
ad_idSource ad identifier, always string.
date_daySource reporting date; no inferred timezone conversion.
spendSource monetary amount in currency_code, six decimal places. Snapchat input is already decimal; no micro-unit division.
impressionsNullable count; null means unknown, not zero.
clicksNullable source clicks; platform definitions can differ.
_batch_idIdentifier of the complete published input snapshot.

marketing_performance

Recommended ad-level consumption view: active rows only. CTR is a fraction, CPC/CPM use the row currency. Zero/unknown denominators yield null.

ColumnMeaning
performance_keyUnique daily performance key.
ctrClicks / impressions as a fraction, not percentage points. Null if clicks unknown or impressions unknown/zero.
cpcSpend / clicks in currency_code. Null for unknown/zero clicks.
cpmSpend / impressions * 1000 in currency_code. Null for unknown/zero impressions.
platformNormalized advertising source.

rpt_campaign_daily

Campaign/day/account/platform/currency reporting view. Country is aggregated away. Complete totals and ratios are null when required inputs are incomplete; known_* columns show partial observations, not complete totals.

ColumnMeaning
source_rowsNumber of ad-level source observations.
known_clicksSum of observed clicks; may be incomplete. Null if none observed.
known_impressionsSum of observed impressions; may be incomplete.
unknown_click_rowsNumber of rows with unknown clicks.
unknown_impression_rowsNumber of rows with unknown impressions.
clicksComplete click count only if every contributing observation is known.
impressionsComplete impression count only if every contributing observation is known.
spendSum of monetary amounts within currency_code.
